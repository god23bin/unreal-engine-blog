> まず一度の Rig を素早く完了したい場合は、 **{% post_link plugin-doc/EasyAutoRig_Tutorial_ja-JP Quick Start Guide %}** を先にご覧ください。このガイドでは、EasyAutoRig のインターフェース、各タブの役割、モデル選択から最終 Asset の生成までの流れをより詳しく説明します。

## 1. EasyAutoRig とは

EasyAutoRig は Unreal Engine 用の人型キャラクター自動リギングプラグインです。要件を満たす**人型スタティックメッシュ**をエディタ内で直接リギングし、設定に応じて次を生成します。

- スケルトン（Skeleton）：UE5 標準人型スケルトンのボーン名、階層、基準の向きを使ってモデルにフィットします
- UE5 形式のツイストボーンと IK ボーン
- 初期自動スキンウェイトを持つスケルタルメッシュ（Skeletal Mesh）
- フィジックスアセット（Physics Asset、生成を無効にできます）

> 自動ウェイトは**初期ウェイト**であり、完成した製品品質のウェイトではありません。リギング後も手動調整が必要で、UE5 内で直接行えます（第 14 節）。

基本的な流れ：

> モデル選択 → ランドマーク自動配置（または手動配置）→ 確認・調整 → リギング検証 → リギング → 結果確認 → UE5 でウェイトを手動調整

**ランドマーク（Landmark）**は最も重要な入力です。その位置が最終的なボーンの関節位置となり、自動スキニングによる体の領域判定にも使われます。適切なランドマークは、スケルトン、スキニング、フィジックスアセットのより確かな基礎になります。

## 2. 入力モデルの要件

EasyAutoRig は**標準的な二足歩行の人型**のみ対応し、次を要件とします。

- T ポーズまたは A ポーズ
- 体がほぼ左右対称
- モデリング時にキャラクターの中心が原点にあり、足裏が `Z = 0` 付近にある
- 向きが次の規約に従っている

```text
+Y = Forward（キャラクター正面）
+Z = Up（頭頂方向）
X  = Left / Right（体の中心線は X = 0）
```

座り、走り、戦闘、腕を交差させた姿勢、片脚を上げた姿勢などは非対応です。T ポーズ／A ポーズの安定した空間関係を使って、左右、腕、脚、膝、胴体などを判定するためです。

プラグインはモデルの回転、移動、スケール、修正を**自動では行いません**。向きや中心が明らかに不適切な場合、検証でエラーや警告が表示されます。DCC ソフトで修正して再インポートしてください。

服、靴、髪、スカート、マント、尻尾、装飾品を含められ、複数の独立したメッシュの塊でも構いません。衣服のない素体である必要はありません。

## 3. EasyAutoRig アセットを作成する

コンテンツブラウザで右クリックし、**アニメーション → EasyAutoRig** を選択します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261647771.png)

プロジェクトの命名規則に従って名前を変更できます（例：`EAR_CharacterName`）。ダブルクリックで EasyAutoRig エディタを開きます。

このアセットには、モデル、ランドマーク、編集切り替え状態、出力フォルダ、最新レポート、その他の設定を保存します。キャラクターごとに 1 つ作成し、再調整時に開き直すことを推奨します。

## 4. エディタのレイアウト

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101623786.png)

### 4.1 ツールバー

中央の区切り線で 2 つのグループに分かれています。

**切り替えグループ**（いつでも有効／無効にでき、状態はアセットに保存されます）：

| ボタン               | 用途                                                         |
| -------------------- | ------------------------------------------------------------ |
| ランドマーク編集     | ビューポートで配置・ドラッグします。無効時は閲覧のみです。   |
| ランドマーク名       | 各点の横に部位名を表示します。                               |
| 関節中心             | クリック・ドラッグ時に、モデル表面ではなく体の内部に配置するモードです。 |
| リアルタイムミラー   | 左側を編集すると、対応する右側の点が自動追従します。         |
| スケルトンプレビュー | 現在のランドマークから生成するスケルトンを表示します。       |

**操作グループ**（作業順）：

| ボタン         | 用途                                                         |
| -------------- | ------------------------------------------------------------ |
| 自動配置       | モデルのビューから体と指のランドマークを自動配置します（第 7 節）。 |
| リギング検証   | 実行可能かを確認し、レポートに問題を表示します（第 10 節）。 |
| リギング       | スケルトンを生成し、モデルを自動でリギングします（第 12 節）。 |
| スケルトンのみ | スケルトンと手動スキニング用モデルを生成し、自動ウェイトは生成しません（第 12.4 節）。 |

### 4.2 パネル

| パネル               | 内容                                                       |
| -------------------- | ---------------------------------------------------------- |
| ビューポート         | モデル、ランドマーク、スケルトンプレビュー、平面ガイド     |
| 詳細                 | ソースモデル、スケルトン（指）、自動スキニング、物理の設定 |
| プレビューシーン設定 | ライト、環境など UE 標準のプレビュー設定                   |
| ランドマーク         | 配置案内、ランドマークツール、ハンドビュー、一覧           |
| レポート             | 検証・リギング結果、自動配置結果、次の操作                 |
| 出力                 | 出力フォルダと生成したアセット                             |

ほとんどのボタンにツールチップがあります。利用できないボタンには、その理由も表示されます。

## 5. 詳細パネル

アセットを開くと、右側に**詳細**パネルが表示されます。通常、変更が必要な設定は少数です。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101704593.png)

### 5.1 入力：ソーススタティックメッシュ

最も重要なのは**入力**カテゴリの**ソーススタティックメッシュ**です。対象の人型スタティックメッシュを選択すると、すぐにビューポートへ表示されます。

先に次を確認してください。

- T ポーズまたは A ポーズか
- 正面が +Y を向いているか
- ほぼ左右対称か
- 体が原点付近にあるか

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261647992.png)

### 5.2 スケルトン：指の設定

標準的な 5 本指で各指が 3 節の場合、**スケルトン**カテゴリの指設定は変更不要です。

指の数や節数が異なる場合は、**ランドマーク配置前に**モデルに合わせて設定してください。

- **左手／右手**の**指の数**（0～5）
- **各指の既定ボーン数**と、親指、人差し指、中指、薬指、小指それぞれのボーン数（1～5）
- 左右が同じ場合、左手を設定してから**手の設定**行の**左手を右手にコピー**をクリック

これらの設定は、必要な指のランドマークと自動配置する指の点を決めます。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261648618.png)

同じカテゴリの**ツイストボーンを生成、IK ボーンを生成、スケルトンプレビューの線の太さ**は、通常は既定値のままにします。

### 5.3 自動スキニング

**自動スキニング**カテゴリには、**推奨既定値**または**カスタム基本ウェイト設定**のどちらを使っているか表示されます。変更した場合は**推奨値にリセット**で一括復元できます。

- **最大ボーン影響数：**1 頂点に影響するボーンの最大数。既定値は 4。
- **基本ウェイト品質（詳細）：**基本ウェイトのソルバーと平滑化のパラメータ。通常は変更不要。

初回はすべて既定値にし、結果を調整する明確な必要がある場合のみ変更してください。

### 5.4 物理

**フィジックスアセットを生成**は既定で有効です。無効にするとスケルトンとスケルタルメッシュのみ生成します。**Legacy UE Auto** のパラメータは旧アセット互換用に残しているもので、現在の物理生成では使用しません。

## 6. ビューポートと観察方向

ランドマークは複数方向から確認します。**正面から高さと左右位置、側面から前後の奥行きを確認してください**。ビューポート左上のビューメニューや UE のショートカットを使います。

EasyAutoRig のキャラクターは `+Y` を向きますが、UE の「前／後／左／右」は UE の座標軸による名前です。キャラクターの正面・側面とは一致しないため、プラグインでは UE のビュー名ではなく「キャラクターの正面／側面から見る」と案内します。

| 見たい方向                     | UE 5.5                         | UE 5.8                 |
| ------------------------------ | ------------------------------ | ---------------------- |
| キャラクター正面（顔が見える） | 右（Right）、`Alt + Shift + K` | 左（Left）、`Alt + K`  |
| キャラクター側面               | 前（Front）、`Alt + H`         | 前（Front）、`Alt + H` |
| パースペクティブ               | `Alt + G`                      | `Alt + G`              |

他のエンジンバージョンは表示結果で判断してください。顔が見える方向が正面です。

## 7. 自動配置

### 7.1 自動配置の処理

ツールバーの**自動配置**をクリックすると、次を実行します。

2. 主要な体の 17 点を書き込み、UE5 Manny スケルトンの比率から脊椎、首の上部、鎖骨を推定して、合計 25 点の体のランドマークを生成します。
3. 各手を手のひら方向から見る個別のハンドビューを生成し、手のキーポイント検出モデルで指を認識してランドマークを書き込みます。
4. 自動検証を実行し、**レポート**を開いて「自動配置完了：N 個のランドマークを推定しました」と通知します。

自動配置で書き込む点はすべて**推定点**です。紫色の中空の円で表示され、一覧では**推定済み・未確定**になります。

### 7.2 変更する点

- **未配置**または**推定状態のまま**で、**ロックされていない**点のみ変更します。
- 手動配置、ドラッグ、ロックした点は変更せず、レポートに「保持」と表示します。
- リアルタイムミラーが有効な場合、左側と中心線の点のみ書き込み、右側は追従します。無効時は左右を個別に書き込みます。
- 全体が 1 回の取り消し操作です。`Ctrl + Z` で取り消せます。変更がなければ取り消し履歴を作らず、アセットも変更済みにしません。

何度実行しても構いません。例えば重要な数点を手動配置してから、残りを自動配置で補えます。

### 7.3 レポートの「自動配置」セクション

完了後、レポート上部に**自動配置**セクションが表示されます。

| 表示内容                                                     | 意味                                                       |
| ------------------------------------------------------------ | ---------------------------------------------------------- |
| N 個のランドマークを自動配置しました                         | 移動または確定するまでは推定点です。                       |
| 手動配置またはロックしたランドマークを保持しました：…        | これらは変更していません。                                 |
| 優先して確認：…（左右の結果が一致しません）                  | 検出結果が異なるため、片側の結果を両側に使いました。       |
| 優先して確認：…（耳が見つからず、首から高さを推定）          | 頭の点の高さを推定しています。                             |
| 優先して確認：…（モデル表面が見つからない／指の厚みを測定できないため奥行きを推定） | 前後位置は推定です。側面から確認してください。             |
| 左手（右手）の指ランドマークを配置できませんでした：理由     | その手の指を手動配置してください。理由は下記。             |
| 左手の指を配置できなかったため、両手に右手の結果を使用       | リアルタイムミラーで、認識できた手をもう一方にも使います。 |
| 必須ランドマークが N 個未配置                                | 手動配置してください。                                     |

指を配置できない主な理由：

- 手首または肘のランドマークが未配置。
- 手をモデルの他の部分から分離できない。
- 握り拳、ミトン状の手、物を持った手などで指を認識できない。
- 一部の指ランドマークが手の外側にある。
- 手の検出モデルをロードできない（NNERuntimeORT を有効にする必要があります）。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101712900.png)

### 7.4 自動配置に失敗した場合

「自動配置でランドマークは変更されませんでした」と通知された場合、アセットに変更はありません。副題に理由が表示されます。

| 理由                                                       | 対応                                                         |
| ---------------------------------------------------------- | ------------------------------------------------------------ |
| 先にソーススタティックメッシュを指定してください           | 詳細でモデルを選択します。                                   |
| 現在のエディタ環境でモデルを描画できない（GPU がないなど） | 手動配置します。                                             |
| 人体検出モデルをロードできない                             | NNERuntimeORT（既定で有効の依存プラグイン）を確認して再試行します。 |
| モデルを正面から見られない                                 | +Y が正面、+Z が上、足裏が Z = 0 か確認します。              |
| 正面ビューに人体が見つからない／人体を確実に検出できない   | 極端なデフォルメ体型などは手動配置します。                   |

## 8. ランドマークパネル

配置と調整に必要なすべてのツールをまとめています。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101713304.png)

### 8.1 ガイドカード

上部カードは状態に応じて次を表示します。

- **タイトル：**未配置点がある場合は**次に配置する点：…**、選択時は**選択中：…**、すべて配置済みなら**関節ランドマークを確認**。
- **状態：**現在の点の配置状況。
- **配置説明：**推奨位置。例えば肘は「上腕と前腕の間の曲がる関節内部に置き、正面から高さ、側面から奥行きを確認」。
- **操作案内：**「モデルをクリックして配置…」「ドラッグで調整、またはこの点を確定をクリック」など。
- **ランドマーク検証：**ツールバーの**リギング検証**と同じ操作。

### 8.2 配置と表示

ツールバーと同じ**ランドマーク編集、関節中心、リアルタイムミラー、ランドマーク名**の 4 つのチェックボックスで、パネルから直接切り替えられます。

### 8.3 ランドマーク

| ボタン                         | 用途                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| この点を確定                   | 選択した推定点を現在位置に保持し、周囲の点による更新を止めます。 |
| すべての推定点を確定           | すべて確定します。先に正面と側面から確認してください。       |
| 最後の点をクリア               | 最後に配置した、ロックされていない点をクリアします。         |
| 選択した点を削除               | 選択点の配置データをクリアします。                           |
| 1 回ミラー                     | 配置済み左側点を、未配置かつ未ロックの右側点へコピーします。リアルタイムミラー無効時に使います。 |
| すべてのランドマークをリセット | ロック済みも含め全点をクリアします。確認画面があり、取り消し可能です。 |

利用できないボタンにポインタを重ねると理由が表示されます。推定に必要な点が残っている場合、自動推定点は削除できません（即座に再推定されるため）。周囲の点を動かすか、その推定点を直接ドラッグしてください。

### 8.4 関節中心

| ボタン                         | 用途                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| 奥行き -／奥行き +             | 選択した関節中心を後方／前方に 1 ステップ移動します。        |
| 中心線                         | 左右の体の中心線に合わせます。骨盤、脊椎、首、頭用で、腕や脚の関節には使いません。 |
| ビュー平面／正面平面／側面平面 | 現在のビュー、キャラクター正面、または側面の平面内にドラッグを制限します。 |
| 平面ガイドを表示／非表示       | ドラッグ平面のガイド（緑色ワイヤーフレーム）を切り替えます。 |
| メッシュを表示／非表示         | 関節中心編集時にモデルを一時的に隠し、遮られた点やボーンを見やすくします。 |

ボタン名はクリック時の操作を示します。**メッシュを非表示**と表示されていれば、現在モデルは表示されています。

### 8.5 ハンドビュー

指のランドマークを配置・確認するために使います。

- **左手の甲、左手のひら、右手の甲、右手のひら：**その手だけを表示し、指を上に向け、甲または手のひら側から手を画面に収めます。
- クリック配置はその手だけに当たるため、手のひら前方の太ももなどを誤選択しません。関節中心が有効ならドラッグは手のひらの平面に沿います。
- **モデル全体を表示：**ハンドビューを終了し、全身を表示して画面に収めます。
- その側の手首と肘を先に配置してください。未配置の場合は利用できません。
- ビュー切り替えはランドマークやアセットデータを変更しません。レポートの「点を確認」操作でも自動でハンドビューを終了します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101645916.png)

### 8.6 前回の操作

「推定ランドマークを 5 個確定」「左肘の奥行きを調整」など、直近の操作結果を表示します。失敗や変更なしの場合も、その結果を表示します。

### 8.7 ランドマーク一覧

| 列       | 内容                                                       |
| -------- | ---------------------------------------------------------- |
| 部位     | 「左肩」「左人差し指の第 2 関節」などのわかりやすい名前    |
| 必要性   | 必須または任意                                             |
| 配置状況 | 未配置、推定済み・未確定、関節中心設定済み、関節中心未設定 |

行をクリックすると対応点を選択します。**関節中心設定済み**はデータがあるという意味だけで、位置の正確さは保証しません。目視確認が必要です。

## 9. ランドマークの配置と調整

### 9.1 ランドマークはボーンの関節位置

ランドマークはスケルトンのフィッティングに直接使われます。**置いた位置に対応するボーンの関節が生成される**と考えてください。

- 左肘（`lowerarm_l`）は肘関節位置を決めます。
- 左膝（`calf_l`）は膝関節位置を決めます。
- 左手首（`hand_l`）は手首位置を決めます。
- 骨盤、脊椎、首は体の中心軸のボーンを決めます。

各点の推奨位置は『EasyAutoRig ランドマークをより適切に配置する方法』を参照してください。

### 9.2 ビューポート内の表示

| 表示           | 意味                                     |
| -------------- | ---------------------------------------- |
| 紫色の中空の円 | 未確定の推定点                           |
| 緑色           | 配置済み、関節中心設定済み               |
| 青色           | 表面に配置済み、関節中心未設定           |
| オレンジ色     | 次に配置する点                           |
| 外側に白い円   | 選択中                                   |
| 半透明         | リアルタイムミラーで左側に追従する右側点 |

### 9.3 推定点と自動推定

脊椎（`spine_01`～`spine_05`）、首の上部（`neck_02`）、鎖骨（`clavicle_l`／`clavicle_r`）は、骨盤、首、頭、肩などを配置すると UE5 Manny の比率から自動推定します。手動配置ではスキップされます。

推定点の規則：

- 周囲の点を動かすと更新します。ドラッグ中は更新せず、マウスを離した時に 1 回更新します。
- ドラッグ、奥行き調整、中心線への整列をすると手動管理の点に変わり、自動更新を停止します。途中に手動配置した点も推定の基準点になります。
- **この点を確定、すべての推定点を確定**は現在位置を保持します。
- 必要な点を削除したり順序が逆になったりした場合（首が骨盤より低いなど）、関連推定点をクリアして手動配置に戻します。

推定点はリギングを妨げません。検証レポートの**提案**に列挙し、**推定ランドマークを確認**ボタンを表示します。

### 9.4 手動配置

1. **ランドマーク編集**を有効にします。**関節中心、リアルタイムミラー**も推奨します。
2. ガイドの**次に配置する点**に従ってモデルをクリックします。
3. 骨盤、脊椎、首、頭など中心線上の点は自動で体の中心線に合わせます。

リアルタイムミラーでは左側のみ配置します。大まかな順序は、骨盤 → 首 1 → 頭 → 左肩 → 左肘 → 左手首 → 左手の指 → 左股関節 → 左膝 → 左足首 → 左足の母指球付近です。

### 9.5 関節中心

有効時に表面をクリックすると、視線に沿ってその場所の体のボリュームを調べ、表面ではなく内部に配置します。肩、肘、手首、股関節、膝、足首に特に有効です。

ただし、ボリュームの中心がアニメーションに最適な関節位置とは限りません。厚い服、スカート、鎧、特殊な体の比率で結果が変わります。素早く初期位置を得るための機能なので、不適切な点は手動調整してください。

### 9.6 ドラッグと平面制限

3 軸が同時に変化して操作しづらくなるのを避けるため、ドラッグは 1 つの平面内に制限します。

- 正面から高さと左右位置を調整するときは**正面平面**。
- 側面から奥行きを調整するときは**側面平面**。
- **ビュー平面**は現在の視点方向に従い、ハンドビューでは手のひらの平面になります。

**平面ガイドを表示**で現在の平面を確認できます。ビューを切り替えても、選択済みの固定平面は自動で変わりません。

### 9.7 リアルタイムミラー

ほぼ左右対称のモデルでは有効にしてください。左側を編集すると右側も更新され、右側点は半透明になります。右側をドラッグした場合、実際の変更は対応する左側点を通して行います。

### 9.8 スケルトンプレビュー

現在のランドマークから生成するスケルトンを直接確認できます。

- 骨盤 → 脊椎 → 首 → 頭が体の中心に沿うか
- 鎖骨 → 上腕 → 前腕 → 手が肩、肘、手首を通るか
- 太もも → すね → 足が股関節、膝、足首を通るか

実際の関節から明らかにずれていたら、対応ランドマークを調整してください。

### 10.5 一部領域に基本ウェイトを使用

1.1.0 から、高度なリギングで領域を確実に認識できない場合（スカート下の股関節、独立メッシュの手、ゆったりした袖の中の腕など）、**その領域だけ** UE Geodesic Voxel の基本ウェイトに切り替えます。他の領域は高度なリギングを維持します。レポートでは次を行います。

- 警告に対象領域と、脚上げやしゃがみなど確認すべき動作を示します。
- 関節中心から外れたランドマークも原因になり得ると案内し、次の手順に確認ボタンを表示します。

失敗ではありませんが、その領域のウェイトは粗いため、優先して動作確認と手動調整を行ってください。検証時にも「手に基本ウェイトを使用する見込み」など、可能な限り事前に予測します。

## 12. リギング、互換モード、スケルトンのみ

### 12.1 リギング

**リギング**をクリックすると：

1. 自動検証し、妨げる問題がある場合は開始しません。
2. 警告がある場合は通知し、**レポートを表示**（生成せずレポートを開く）または**続行**を選べます。
3. 「キャラクターをリギング中…」の進捗を表示し、スケルトン、自動スキニング、スケルタルメッシュ、フィジックスアセットを順に生成して出力の妥当性を確認します。
4. レポートに結果を表示し、生成アセットを自動で開きます。自動表示はプロジェクト設定で無効にできます。

### 12.2 自動スキニングの選択方法

アルゴリズムを手動で選ぶ必要はありません。次の順に処理します。

1. **高度なリギング**（診断名 `SemanticFull`）：頭・首、胴体、肩、腕、肘、手首、手、股関節、太もも、膝、すね、足などを認識し、領域別にウェイトを生成します。最も高品質な方法です。
2. **一部領域に基本ウェイト：**認識できない領域だけ基本ウェイトを使います（10.5）。
3. **互換モード**（診断名 `GeodesicCompatibility`）：モデル全体が高度なリギングに適さない場合や内部エラー時に、UE Geodesic Voxel で全体の基本自動ウェイトを生成します。内部エラーによる自動切り替え時は、完全なレポートを作者へ送るよう案内します。
4. **スケルトンのみ：**基本ウェイトすら妥当に生成できない場合はスケルトンのみ確定し、手動スキニングが必要と説明します。

どの方法も同じ妥当性チェックを通過してからアセットに書き込みます。また、どの自動ウェイトも**初期ウェイト**であり、手動調整が必要です（第 14 節）。基本ウェイトと互換モードはより粗く、調整箇所が増えます。

### 12.3 互換モードでリギング

「このモデルでは高度な自動リギングが完了しませんでした」と表示された場合、次の手順に**互換モードでリギング**が現れます。クリックすると**リギングを再実行**します。

- 高度な体の領域分析を省き、UE Geodesic Voxel で基本自動ウェイトを生成します。
- ランドマークは変更しません。
- より粗いウェイトになるため、肩、股関節、手、指をさらに手動調整してください。

この選択はアセットに保存しません。次に**リギング**を押すと、再び高度なリギングから試します。

### 12.4 スケルトンのみ

自動ウェイトが不要、またはすべて自分で描く場合は**スケルトンのみ**を使います。スケルトンと手動スキニング用モデルアセット（有効なら物理アセットも）を生成し、自動ウェイトは生成しません。後から UE、Blender、Maya で描けます。

ボーン作成、名前付け、階層、ツイストボーン、IK ボーンなどの反復作業を省けます。

## 13. リギング結果を確認する

自動リギング成功後、**リギング結果を確認**カードを表示します。

1. **リギング済みモデルを開く：**スケルタルメッシュエディタで生成キャラクターを開きます。
2. **プレビューアニメーションを選択：**プレビューシーン設定でプレビューコントローラを**指定アニメーションを使用**にし、アニメーションを選択します。このスケルトンと互換性があるもの、またはリターゲット済みのものを使ってください。
3. **腕を上げる：**両肩と脇の潰れ、過度な伸び、胸の意図しない動きを確認します。
4. **肘と膝を曲げる：**明らかな折れ込み、潰れ、伸びを確認します。
5. **指を曲げる：**手を開く／握る動作で各指が自分の関節に沿って曲がり、隣の指が意図せず追従しないか確認します。

適切なアニメーションがない場合はプレビューコントローラを**参照ポーズ（Reference Pose）**にし、**Character > Bones > All Hierarchy** でスケルトンを表示して、正面と側面から位置を確認します。静止ポーズでは曲げた際の変形を確認できません。

ボーン位置のずれで変形が明らかにおかしい場合（肘が曲がる位置にないなど）は、対応点を正面・側面から確認して調整し、再検証・再リギングします。位置が適切になったら、残る変形問題はウェイト手動調整で修正します（第 14 節）。動作異常はアニメーション自体が原因の場合もあります。原因不明ならサポート用レポートをコピーしてください。

## 14. UE5 でウェイトを調整する

自動ウェイトは早く動かしてテストするための**初期ウェイト**で、**完成した製品品質ではありません**。「使える」（再生でき、明らかな破綻がない）ことは完成品質を意味せず、手動調整が必要です。作業量はトポロジー、比率、服、髪、分離パーツで変わります。

Blender や Maya に書き出さず、UE5 内で直接調整できます。UE 5.5 のスケルタルメッシュエディタには標準で編集ツールがあります。

1. 生成スケルタルメッシュを開きます。レポートの**リギング済みモデルを開く**も使えます。
2. **Editing Tools** をクリックし、**Skin** の **Edit Weights** を選びます。
3. ボーン一覧で対象を選び、ブラシで描きます。
   - **Add：**選択ボーンのウェイトを加算
   - **Replace：**指定値に置換
   - **Multiply：**比例して増減
   - **Relax：**ウェイトの遷移を平滑化
4. 頂点を選択して **Mirror**（反対側にミラー）、**Flood**（一括適用）、**Prune**（小さすぎる影響を除去）、**Relax** なども使えます。
5. **Accept** で適用して保存します。

推奨順序：

1. 腕上げ、肘曲げ、脚上げ、しゃがみ、握り拳をプレビューしながら調整します。
2. 肩と脇、肘、手首、股関節と鼠径部、膝などの主要関節から始めます。
3. 次に指。
4. 最後に服、髪、スカート、マント、装飾品。
5. 左右対称の場合、片側を仕上げて **Mirror** で反対側にコピーします。

**Editing Tools** がない場合は、**編集 → プラグイン**で **Skeletal Mesh Editing Tools** を有効にして再起動してください。UI 名称はエンジンバージョンや言語で多少異なります。

## 15. スクリプトと AI インターフェース

エディタ用スクリプトライブラリ `EasyAutoRigEditorScriptingLibrary` を提供しています。UE 5.5～5.8 で Python（`unreal.EasyAutoRigEditorScriptingLibrary`）またはエディタブループリントから、設定とランドマークの読み取り、自動配置、配置／確定／クリア、検証、リギング、レポート読み取りを呼び出せます。ボタンとまったく同じ規則に従い、実行前の検証や警告の明示的な承認も必要です。

UE 5.8 で Toolset Registry が有効な場合、AI ツールとワークフロースキルも登録します。MCP 接続の AI アシスタントは「自動配置 → 列挙された点の確認 → 検証 → ユーザーの同意を得てリギング」の手順で操作できます。

## 16. 推奨操作順序

標準的な人型モデルでは、重点的に行うことは 3 つです。

1. **要件を満たすスタティックメッシュを選択**。5 本指でない場合は先に指設定を行います。
2. **自動配置してランドマークを確認・調整**。特にレポートの優先確認点と指を確認します。
3. **レポートに基づいて判断**。直接リギング、問題を解決して再検証、または互換モード／スケルトンのみを選びます。

その後、実際のアニメーションで結果を確認し、プロジェクト要件を満たすまで UE5 でウェイトを手動調整してください。
