> 如果您只是想快速完成一次绑定，可以先阅读 **{% post_link plugin-doc/EasyAutoRig使用教程 EasyAutoRig 快速入门指南 %}** 。本文则更详细地介绍 EasyAutoRig 的界面、各个标签页的作用，以及从选择模型到最终生成资产的完整使用逻辑。

## 1. EasyAutoRig 是什么？

EasyAutoRig 是一款 Unreal Engine 人形角色自动绑定插件。它把符合要求的**人形静态网格体**直接在编辑器中绑定，并根据设置生成：

- 骨架（Skeleton）：按 UE5 标准人形骨架的骨骼名称、层级和参考朝向拟合到你的模型
- UE5 风格的 Twist 骨骼、IK 骨骼
- 带初始自动蒙皮权重的骨骼网格体（Skeletal Mesh）
- 物理资产（Physics Asset，可关闭）

> 自动权重是**初始权重**，不是生产级权重。绑定后仍然需要手工调整权重，可以直接在 UE5 中完成（见第 14 节）。

基本工作方式：

> 选择模型 → 自动放置（或手动放置）标记点 → 检查和调整 → 验证绑定 → 绑定 → 检查结果 → 在 UE5 中手工调整权重

**标记点（Landmark）**是整个流程中最重要的输入：它们的位置就是最终骨骼关节的位置，也是自动蒙皮判断身体区域的依据。标记点越合理，骨架、蒙皮和物理资产的基础就越可靠。

## 2. 输入模型要求

EasyAutoRig 只支持**标准双足人形**，并要求：

- T Pose 或 A Pose
- 左右身体基本对称
- 角色在建模时以原点为中心，脚底在 `Z = 0` 附近
- 朝向符合下面的约定：

```text
+Y = Forward（角色正面）
+Z = Up（头顶方向）
X  = Left / Right（身体中线在 X = 0）
```

坐姿、跑步、战斗姿势、双手交叉、单腿抬起等动作姿势不属于支持的输入。原因是插件依赖 T Pose / A Pose 中稳定的人体空间关系，来判断左右、手臂、腿、膝盖和躯干等区域。

插件**不会**自动旋转、移动、缩放或修正模型。朝向或中心明显不对时，验证会给出错误或警告。请在 DCC 软件中修正后重新导入。

模型可以包含衣服、鞋子、头发、裙子、披风、尾巴、饰品，也可以由多个独立网格块组成，不要求是裸模。

## 3. 创建 EasyAutoRig 资产

在内容浏览器中右键，选择「动画 → EasyAutoRig」，即可创建 EasyAutoRig 资产。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261647771.png)

可以按项目命名规则重命名，例如 `EAR_CharacterName`。双击资产即可打开 EasyAutoRig 编辑器。

这个资产会保存所选模型、标记点、编辑开关状态、输出目录、最近一次报告和其他设置。建议一个角色对应一个 EasyAutoRig 资产，以后想重新调整时直接打开它。

## 4. 编辑器布局

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101623786.png)

### 4.1 工具栏

工具栏分为两组，中间以分隔线隔开。

**开关组**（可以随时打开或关闭，状态保存在资产中）：

| 按钮     | 作用                                                         |
| -------- | ------------------------------------------------------------ |
| 编辑标记 | 在视口中放置、拖动标记点。关闭时只能查看。                   |
| 标记名称 | 在视口中每个标记点旁显示身体部位名称。                       |
| 关节中心 | 关节中心模式：点击和拖动时，标记点落在身体内部，而不是模型表面。 |
| 实时镜像 | 编辑左侧标记点时，右侧对应点自动跟随。                       |
| 骨骼预览 | 按当前标记点显示将要生成的骨架。                             |

**操作组**（按工作顺序排列）：

| 按钮       | 作用                                                         |
| ---------- | ------------------------------------------------------------ |
| 自动放置   | 根据模型的视图自动放置身体和手指标记点（见第 7 节）。        |
| 验证绑定   | 检查是否可以开始绑定，并在「报告」中列出问题（见第 10 节）。 |
| 绑定       | 生成骨架，并把模型自动绑定到骨架上（见第 12 节）。           |
| 仅绑定骨骼 | 生成骨架和供手动蒙皮使用的模型资产，不生成自动权重（见第 12.4 节）。 |

### 4.2 面板

| 面板         | 内容                                             |
| ------------ | ------------------------------------------------ |
| 视口         | 模型、标记点、骨骼预览、平面辅助线。             |
| 细节         | 资产设置：源模型、骨架（手指）、自动蒙皮、物理。 |
| 预览场景设置 | UE 标准的预览场景设置（灯光、环境等）。          |
| 标记         | 放置指引、标记点工具、手部视图、标记点列表。     |
| 报告         | 验证与绑定结果、自动放置结果、下一步操作。       |
| 输出         | 输出目录和生成的资产。                           |

绝大多数按钮都有提示文字（Tool Tip）。按钮不可用时，提示中还会写明原因。

## 5. 细节面板

打开 EasyAutoRig 资产后，右侧是「细节」面板。大多数情况下，真正需要修改的设置很少。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101704593.png)

### 5.1 输入：源静态网格体

最重要的设置是「输入」分类中的「**源静态网格体**」。选择需要绑定的人形静态网格体后，模型会立即显示在视口中。

建议先确认：

- 是否为 T Pose 或 A Pose
- 是否正面朝向 +Y
- 左右是否基本对称
- 人体位置是否在原点附近

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261647992.png)

### 5.2 骨架：手指设置

如果模型是标准五指手、每根手指 3 节，「骨架」分类中的手指设置不需要修改。

如果手指数量或骨节数不同，请在**放置标记点之前**按模型实际情况设置：

- 「左手」「右手」中的「手指数量」（0～5）
- 「每根手指默认骨骼数」，以及拇指、食指、中指、无名指、小指各自的骨骼数（1～5）
- 左右手相同时，设置好左手后点击「手部设置」行的「**将左手复制到右手**」

手指设置会决定需要哪些手指标记点，也决定自动放置会放哪些手指点。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261648618.png)

同一分类中还有「生成扭转骨骼」「生成 IK 骨骼」和「骨骼预览线条粗细」，一般保持默认。

### 5.3 自动蒙皮

「自动蒙皮」分类显示当前是「推荐默认值」还是「自定义基础权重设置」。改动过的话，可以点击「**重置为推荐值**」一键恢复。

- 「最大骨骼影响数」：每个顶点最多受几根骨骼影响，默认 4。
- 「基础权重质量（高级）」：基础权重的求解器与平滑参数，通常不需要修改。

建议第一次使用时全部保持默认，只有在明确需要调整结果时再修改。

### 5.4 物理

「生成物理资产」默认开启。关闭后，绑定只生成骨架和骨骼网格体。「Legacy UE Auto」中的参数只为兼容旧资产保留，当前的物理资产生成不使用它们。

## 6. 视口与观察方向

标记点需要从多个方向检查：**从角色正面检查高度和左右位置，从角色侧面检查前后深度。**请使用视口左上角的视图菜单切换观察方向，或使用 UE 的快捷键。

注意：EasyAutoRig 的角色面向 `+Y`，而 UE 视图菜单中的“前 / 后 / 左 / 右”是按 UE 自己的坐标轴命名的，和角色的正面、侧面并不对应。因此插件的提示文字都使用“从角色正面 / 侧面观察”，而不使用 UE 的视图名称：

| 想看                 | UE 5.5                                 | UE 5.8                         |
| -------------------- | -------------------------------------- | ------------------------------ |
| 角色正面（能看到脸） | 「右（Right）」视图，`Alt + Shift + K` | 「左（Left）」视图，`Alt + K`  |
| 角色侧面             | 「前（Front）」视图，`Alt + H`         | 「前（Front）」视图，`Alt + H` |
| 透视                 | `Alt + G`                              | `Alt + G`                      |

其他引擎版本以画面为准：能看到角色的脸就是正面。

## 7. 自动放置

### 7.1 自动放置做了什么

点击工具栏的「**自动放置**」后，插件会：

2. 写入 17 个主要身体点，再按 UE5 Manny 骨架的比例推算出脊柱、上颈部和锁骨的点，共 25 个身体点；
3. 为每只手沿手掌方向单独生成手部视图，用手部关键点模型识别手指，写入手指标记点；
4. 自动执行一次验证，打开「报告」面板，并弹出通知“自动放置完成：已估算 N 个标记点”。

自动放置写入的点都是**估算点**，在视口中显示为紫色空心圈，列表中状态为「已估算，未确认」。

### 7.2 哪些点会被修改

- 只修改**未放置**或**仍是估算点**且**未锁定**的点；
- 你放置、拖动或锁定过的点不会被修改，报告中会列为“已保留”；
- 开启实时镜像时，只写左侧和中线点，右侧跟随左侧；关闭时左右两侧分别写入；
- 整个自动放置是一个撤销步骤，`Ctrl + Z` 一次即可撤回；没有任何点被修改时，不会产生撤销步骤，资产也不会被标记为已修改。

因此可以放心地多次点击：比如先自己放好几个关键点，再用自动放置补齐其余的点。

### 7.3 报告中的「自动放置」段落

自动放置完成后，「报告」顶部会出现「**自动放置**」段落。可能出现的内容：

| 内容                                                         | 含义                                             |
| ------------------------------------------------------------ | ------------------------------------------------ |
| 已自动放置 N 个标记点                                        | 这些点在你移动或确认前，会一直标为估算点。       |
| 已保留您放置或锁定的标记点：…                                | 这些点没有被改动。                               |
| 请优先检查：…（左右两侧结果不一致）                          | 检测时左右结果不一致，两侧都采用了同一侧的结果。 |
| 请优先检查：…（未找到耳朵，高度根据颈部估算）                | 头部点的高度是推算的。                           |
| 请优先检查：…（未找到模型表面 / 无法测量手指厚度，深度为推测值） | 这些点的前后深度是猜测值，请从侧面检查。         |
| 未放置左手（右手）手指标记点：原因                           | 这只手需要手动放置手指，原因见下表。             |
| 未能放置左手手指，两只手都采用了右手手指的结果               | 开启实时镜像时，用识别成功的一只手代替另一只手。 |
| 仍有 N 个必需标记点未放置                                    | 请手动放置这些点。                               |

手指未放置的常见原因：

- 手腕或手肘标记点尚未放置；
- 无法将手部与模型的其余部分分开；
- 无法识别手指，例如握拳、手套状的手或手中握着物体；
- 有手指标记点落在了手部之外；
- 无法加载手部检测模型（需启用 NNERuntimeORT 插件）。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101712900.png)

### 7.4 自动放置失败时

如果弹出通知“自动放置未更改任何标记点”，资产不会有任何改动。副标题会说明原因：

| 原因                                              | 处理                                                        |
| ------------------------------------------------- | ----------------------------------------------------------- |
| 请先指定源静态网格体                              | 在「细节」中选择模型。                                      |
| 当前编辑器会话无法渲染模型（例如没有 GPU）        | 手动放置。                                                  |
| 无法加载人体检测模型                              | 确认已启用 NNERuntimeORT 插件（插件依赖，默认启用）后重试。 |
| 无法从正面查看模型                                | 检查模型是否面向 +Y、+Z 朝上、脚底位于 Z = 0。              |
| 在模型的正面视图中未找到人体 / 无法可靠地检测人体 | 例如比例非常夸张的风格化角色，请手动放置。                  |

## 8. 标记面板

「标记」面板集中了放置和调整标记点所需的所有工具。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101713304.png)

### 8.1 指引卡片

面板顶部的卡片会根据当前状态显示：

- **标题**：「下一个放置点：…」（还有点未放置时）、「当前选中：…」（选中了某个点时）或「检查关节标记点」（全部放置后）；
- **状态**：当前点的放置进度；
- **放置说明**：这个身体部位应该放在哪里，例如肘部“放在上臂与前臂之间的弯曲关节内部，从正面检查高度，从侧面检查深度”；
- **操作提示**：例如“点击模型放置…”“拖动调整或点击「确认此点」”；
- 「**验证标记点**」按钮：与工具栏的「验证绑定」相同。

### 8.2 放置与显示

与工具栏开关相同的四个复选框：「编辑标记」「关节中心」「实时镜像」「标记名称」，方便在面板中直接切换。

### 8.3 标记点

| 按钮           | 作用                                                         |
| -------------- | ------------------------------------------------------------ |
| 确认此点       | 把选中的估算点保留在当前位置，此后它不再随周围的点更新。     |
| 确认全部估算点 | 确认所有估算点。建议先从正面和侧面检查。                     |
| 清除最后一个   | 清除最近放置的、未锁定的标记点。                             |
| 删除选中的     | 清除选中标记点的放置数据。                                   |
| 镜像一次       | 把已放置的左侧点复制到空的、未锁定的右侧点（不开启实时镜像时使用）。 |
| 重置所有标记   | 清除所有标记点（包括已锁定的）。会先弹出确认，可撤销。       |

按钮不可用时，鼠标停在按钮上可以看到原因。例如：推算所需的点还在时，自动推算出的估算点不能删除（删除后会立即重新推算），请移动周围的点或直接拖动它。

### 8.4 关节中心

| 按钮                           | 作用                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| 深度 - / 深度 +                | 把选中的关节中心向后 / 向前移动一个步长。                    |
| 中心线                         | 把选中点移到身体左右之间的中线上。适用于骨盆、脊柱、颈部、头部；不用于手臂或腿的关节。 |
| 视图平面 / 正面平面 / 侧面平面 | 拖动时限制在当前视图平面、角色正面平面或角色侧面平面内移动。 |
| 显示 / 隐藏平面辅助线          | 显示或隐藏当前拖动平面的辅助线（视口中的绿色线框）。         |
| 显示 / 隐藏网格体              | 编辑关节中心时临时隐藏模型，方便看到被遮挡的标记点和骨骼。   |

按钮上的文字表示“点击后会执行的操作”，例如显示「隐藏网格体」说明当前模型是显示的。

### 8.5 手部视图

用于放置和检查手指标记点：

- 「左手手背」「左手手掌」「右手手背」「右手手掌」：视口只显示这一只手，手指朝上，从手背或手掌一侧观察，并框住这只手；
- 手部视图中，单击放置只会落在这只手上（不会点到手掌前面的大腿）；开启关节中心时，拖动沿手掌平面进行；
- 「**显示完整模型**」：退出手部视图，恢复全身并框住整个模型；
- 需要该侧的手腕和手肘标记点已放置，否则按钮不可用；
- 标记点和资产数据不会因为切换视图而改变。从报告中点击“检查某个点”时也会自动退出手部视图。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101645916.png)

### 8.6 上次操作

显示最近一次标记点操作的结果，例如“已确认 5 个估算的标记点”“已调整左肘标记点的深度”。操作失败或没有改变时也会如实说明。

### 8.7 标记点列表

| 列       | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 身体部位 | 可读的部位名称，例如“左肩”“左食指第2关节”。                  |
| 是否必要 | 「必需」或「可选」。                                         |
| 放置进度 | 「未放置」「已估算，未确认」「关节中心已设置」「关节中心未设置」。 |

点击列表中的一行即可选中对应标记点。注意：“关节中心已设置”只说明有关节中心数据，不代表位置一定准确，仍需目视检查。

## 9. 标记点的放置与调整

### 9.1 标记点就是骨骼关节

标记点直接参与骨架拟合，可以简单理解为：**标记点放在哪里，对应的骨骼关节就会生成在哪里。**例如：

- 左肘（`lowerarm_l`）决定肘关节位置；
- 左膝（`calf_l`）决定膝关节位置；
- 左手腕（`hand_l`）决定手腕位置；
- 骨盆、脊柱、颈部决定身体中轴骨骼。

每个点在身体上的推荐位置，请参考《EasyAutoRig 如何更好地放置标记？》。

### 9.2 视口中的标记点样式

| 样式         | 含义                         |
| ------------ | ---------------------------- |
| 紫色空心圈   | 估算点，尚未确认             |
| 绿色         | 已放置，关节中心已设置       |
| 蓝色         | 已放置在表面，关节中心未设置 |
| 橙色         | 下一个要放置的点             |
| 外加白色圆圈 | 当前选中                     |
| 半透明       | 实时镜像下由左侧带动的右侧点 |

### 9.3 估算点与自动推算

脊柱（`spine_01`～`spine_05`）、上颈部（`neck_02`）和锁骨（`clavicle_l` / `clavicle_r`）的点，会在骨盆、颈部、头部、肩等点放好后，按 UE5 Manny 骨架的比例自动推算。因此手动放置时面板会跳过它们。

估算点的规则：

- 移动它周围的点时，估算点会跟着更新（拖动过程中不更新，松开鼠标时更新一次）；
- 你拖动、调整深度或对齐中线后，它就成为你自己的点，不再自动更新；你在中间亲手放的点也会成为推算的锚点；
- 「确认此点」「确认全部估算点」让估算点保持当前位置；
- 推算所需的点被删除或顺序颠倒（例如颈部低于骨盆）时，相关估算点会被清除，交回给你手动放置。

估算点不会阻止绑定。验证时报告会在「建议」中列出它们，并提供「检查估算的标记点」按钮。

### 9.4 手动放置

1. 开启「编辑标记」（建议同时开启「关节中心」「实时镜像」）；
2. 按指引卡片中的「下一个放置点」点击模型；
3. 中线上的点（骨盆、脊柱、颈部、头部）会自动对齐身体中线。

开启实时镜像时只需要放左侧。放置顺序大致为：骨盆 → 颈部 1 → 头部 → 左肩 → 左肘 → 左手腕 → 左手手指 → 左髋 → 左膝 → 左脚踝 → 左前脚掌。

### 9.5 关节中心

开启「关节中心」后，点击模型表面时，插件会沿视线找到这一处身体的体积，把点放到体积内部，而不是表面。这对肩、肘、腕、髋、膝、踝特别有用。

不过，体积中心不一定就是动画上最合适的关节位置：厚衣服、裙子、护甲、特殊比例都会影响结果。所以关节中心是一个快速的初始结果，看到不合适的点仍需要手动调整。

### 9.6 拖动与平面限制

拖动标记点时，点只在一个平面内移动，避免三个方向同时变化难以控制：

- 正面调整高度和左右位置时，用「正面平面」；
- 侧面调整前后深度时，用「侧面平面」；
- 「视图平面」跟随当前视图方向；手部视图中就是手掌平面。

配合「显示平面辅助线」，可以直观看到当前平面。切换视口视图时，已选的固定平面不会自动改变。

### 9.7 实时镜像

模型左右基本对称时，建议开启实时镜像。编辑左侧点时右侧同步更新，右侧点在视口中显示为半透明。拖动右侧点时，实际修改会通过对应的左侧点完成。

### 9.8 骨骼预览

开启「骨骼预览」后，可以直接看到当前标记点生成的骨架。重点检查：

- 骨盆 → 脊柱 → 颈部 → 头部 是否沿身体中心
- 锁骨 → 上臂 → 前臂 → 手 是否经过肩、肘、腕
- 大腿 → 小腿 → 脚 是否经过髋、膝、踝

骨骼明显偏离真实关节时，回到对应标记点调整。

## 10. 报告面板

### 10.1 尚未验证时

还没有验证过时，报告显示「**绑定前请先检查**」和一个「验证绑定」按钮。修改任何标记点后，上一次的报告也会失效，需要重新验证。

### 10.2 状态卡片

验证或绑定后，报告顶部是带颜色的状态卡片：标题、摘要，以及“错误 / 警告 / 建议”的数量。

**验证后的状态**：

| 标题                     | 含义                                                         |
| ------------------------ | ------------------------------------------------------------ |
| 基础检查通过             | 没有发现会阻止绑定的问题，可以开始绑定。关节位置和变形效果仍需目视确认。 |
| 可以开始绑定，请检查警告 | 可以绑定，但请先看警告和骨骼预览。                           |
| 请先处理问题，再进行绑定 | 发现了阻止绑定的问题，请按「下一步」处理后重新验证。         |

**绑定后的状态**：

| 标题                              | 含义                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| 绑定完成                          | 自动绑定完成。请打开生成的角色，预览动作检查结果。           |
| 绑定完成 - 部分区域使用了基础权重 | 部分身体区域无法可靠识别，使用了基础权重，其余区域照常使用高级绑定（见 10.5）。 |
| 已使用兼容模式完成绑定            | 高级绑定出现内部错误或你选择了兼容模式，整体使用基础自动权重。 |
| 骨架已生成，需要手动绑定          | 只生成了骨架，自动权重没有完成。                             |
| 骨架准备完成                      | 「仅绑定骨骼」的结果，需要手动添加蒙皮权重。                 |
| 绑定未完成                        | 绑定失败，请看报告中的原因和「下一步」。                     |
| 绑定已取消                        | 你取消了绑定，可以随时重新开始。                             |

### 10.3 报告分区

| 分区                   | 内容                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 自动放置               | 刚执行过自动放置时出现（见 7.3）。下次验证或修改标记点后消失。 |
| 检查绑定结果           | 自动绑定成功后出现的检查步骤卡片（见第 13 节）。             |
| 下一步                 | 针对当前问题的操作按钮（见 10.4）。没有需要处理的事项时不显示。 |
| 绑定                   | 用一句话说明这次会如何绑定，或这次是如何完成的。             |
| 错误                   | 阻止绑定的问题。                                             |
| 警告                   | 可以绑定，但需要你留意的问题。                               |
| 建议                   | 不影响绑定的提示，例如有未确认的估算点、体型比例与 Manny 差异较大。 |
| 诊断信息（供技术支持） | 默认折叠，包含技术细节和「复制完整报告」按钮。普通使用不需要看。 |

### 10.4 「下一步」中的按钮

| 按钮                   | 作用                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 检查左肘（等具体部位） | 选中这个点，开启关节中心模式，并让视口对准它。从正面和侧面检查，必要时调整后重新验证。 |
| 检查关节标记点         | 打开标记面板，从正面和侧面检查各个关节点。                   |
| 检查估算的标记点       | 选中第一个估算点并进入关节中心模式。                         |
| 补齐缺失标记点         | 选中第一个缺失的必需点，显示整个模型。                       |
| 打开输入设置           | 打开「细节」面板，检查源静态网格体。                         |
| 重新验证               | 再次执行验证。                                               |
| 使用兼容模式绑定       | 高级绑定未能完成时出现，见 12.3。                            |
| 复制报告供技术支持     | 复制完整报告到剪贴板。                                       |

这些按钮只会帮你选中和查看，不会自动移动、镜像或确认你的标记点。

### 10.5 部分区域使用基础权重

1.1.0 起，当高级绑定无法可靠识别某个身体区域时（例如裙子下的髋部、单独网格块做的手、宽松袖子里的手臂），**只有这个区域**改用基础权重（UE Geodesic Voxel 生成的权重），身体其余部分仍然使用高级绑定。报告会：

- 在警告中说明哪些区域使用了基础权重，以及绑定后应该测试哪些动作（例如抬腿、下蹲）；
- 提醒“这些区域的标记点不在关节中心也可能导致这种情况”，并在「下一步」中给出这些点的检查按钮。

这不是失败，但这些区域的权重更粗略，绑定后请优先测试并手工调整这些区域。验证时插件也会尽量提前预测，例如“预计手部将使用基础权重”。

## 12. 绑定、兼容模式与仅绑定骨骼

### 12.1 绑定

点击「**绑定**」后：

1. 插件先自动验证一次。有阻止绑定的问题时不会开始；
2. 有警告时弹出通知，可选择「查看报告」（不生成资产，打开报告）或「继续」；
3. 显示进度窗口“正在绑定角色……”，依次生成骨架、自动蒙皮、骨骼网格体和物理资产，最后检查输出是否合法；
4. 完成后报告显示结果，生成的资产自动打开（可在项目设置中关闭）。

### 12.2 自动蒙皮是怎样选择的

你不需要手动选择算法，插件会按下面的顺序处理：

1. **高级绑定**（报告诊断中称为 SemanticFull）：识别头颈、躯干、肩、手臂、肘、手腕、手、髋、大腿、膝、小腿、脚等身体区域，按区域生成权重。这是质量最高的方式；
2. **部分区域使用基础权重**：某个区域无法可靠识别时，只有这个区域使用基础权重（见 10.5）；
3. **兼容模式**（诊断中称为 GeodesicCompatibility）：模型整体不适合高级绑定，或高级绑定出现内部错误时，整体使用 UE Geodesic Voxel 生成基础自动权重。出现内部错误自动切换时，报告会请你复制完整报告发给作者；
4. **只有骨架**：连基础权重也无法合法生成时，只提交骨架，并在报告中说明需要手动蒙皮。

无论哪种方式，最终都会经过同样的合法性检查后才写入资产。也无论哪种方式，自动生成的都是**初始权重**，绑定后都需要手工调整（见第 14 节）；基础权重和兼容模式的权重更粗略，需要调整的地方更多。

### 12.3 使用兼容模式绑定

如果报告显示“此模型未能完成高级自动绑定”，「下一步」中会出现「**使用兼容模式绑定**」按钮。点击后会**重新绑定一次**：

- 跳过高级的身体部位分析，直接用 UE Geodesic Voxel 生成基础自动权重；
- 你的标记点不会被修改；
- 兼容模式的权重比高级绑定更粗略，完成后肩部、髋部、手和手指需要更多手工调整。

这个选择不会保存在资产中，下次点击「绑定」仍然会先尝试高级绑定。

### 12.4 仅绑定骨骼

如果不需要自动权重，或者准备完全自己绘制权重，可以点击「**仅绑定骨骼**」。它会生成骨架和供手动蒙皮使用的模型资产（开启时还会生成物理资产），不生成自动权重。之后可以在 UE、Blender 或 Maya 中绘制权重。

这样仍然省掉了骨骼创建、命名、层级、Twist 骨骼和 IK 骨骼等大量重复工作。

## 13. 检查绑定结果

自动绑定成功后，报告会显示「**检查绑定结果**」卡片：

1. **打开已绑定模型**：点击按钮，在骨骼网格体编辑器中打开生成的角色；
2. **选择预览动画**：在「预览场景设置」中，把「预览控制器」设为「使用指定动画」，再选择「动画」。请使用与这个骨架兼容或已重定向到这个骨架的动画；
3. **抬起手臂**：观察两侧肩部和腋下，检查是否明显塌陷、过度拉伸或胸部意外移动；
4. **弯曲肘部和膝部**：检查弯曲处是否出现明显夹折、塌陷或拉伸；
5. **弯曲手指**：使用手部张开与握合的动画，检查每根手指是否沿自身关节弯曲、相邻手指是否意外跟随。

暂时没有合适的动画时，可以把「预览控制器」设为「参考姿势（Reference Pose）」，并通过视口的「Character > Bones > All Hierarchy」显示骨架，从正面和侧面检查骨架位置。静止姿势无法展示弯曲时的变形。

如果变形明显不对，并且是骨骼位置偏了（例如肘关节不在手臂弯曲处），先回到对应标记点从正面和侧面检查，调整后重新验证并再次绑定。骨架位置合理后，剩下的变形问题需要手工调整权重（见第 14 节）。动作异常也可能与动画本身有关，原因不明时请复制报告供技术支持。

## 14. 在 UE5 中调整权重

EasyAutoRig 生成的自动权重是**初始权重**，作用是让角色尽快动起来、方便尽早测试，**不是生产级权重**。权重“能用”（能播放动画、没有明显破面）不代表已经达到生产级别，绑定后仍然需要手工调整。需要调整的工作量取决于模型的拓扑、比例、衣服、头发和分离部件。

好消息是可以直接在 UE5 中调整，不需要导出到 Blender 或 Maya。UE 5.5 的骨骼网格体编辑器默认带有权重编辑工具：

1. 打开生成的骨骼网格体（可以在报告中点击「打开已绑定模型」）；
2. 点击工具栏中的「Editing Tools」，切换到「Skin」分类，选择「Edit Weights」；
3. 在骨骼列表中选中要调整的骨骼，用笔刷绘制权重：
   - Add：增加所选骨骼的权重
   - Replace：把权重替换为指定值
   - Multiply：按比例放大或缩小权重
   - Relax：平滑权重的过渡
4. 也可以选中一部分顶点，使用 Mirror（把一侧的权重镜像到另一侧）、Flood（整体赋值）、Prune（清除过小的影响）、Relax 等操作；
5. 调整完成后点击「Accept」应用，再保存资产。

建议的调整顺序：

1. 一边播放预览动画（抬臂、弯肘、抬腿、下蹲、握拳）一边调整；
2. 先处理身体主要关节：肩和腋下、肘、手腕、髋和腹股沟、膝；
3. 再处理手指；
4. 最后处理衣服、头发、裙子、披风、饰品；
5. 左右对称的角色可以先调好一侧，再用 Mirror 镜像到另一侧。

如果工具栏中没有「Editing Tools」，请在「编辑 → 插件」中搜索并启用「Skeletal Mesh Editing Tools」，重启编辑器。界面名称可能因引擎版本和编辑器语言略有不同。

## 15. 脚本与 AI 接口

EasyAutoRig 提供编辑器脚本库 `EasyAutoRigEditorScriptingLibrary`，在 UE 5.5～5.8 中都可以通过 Python（`unreal.EasyAutoRigEditorScriptingLibrary`）或编辑器蓝图调用：读取设置和标记点、自动放置、放置 / 确认 / 清除标记点、验证、绑定、读取报告。它与编辑器按钮使用完全相同的规则，例如绑定前同样会先验证，有警告时必须显式接受。

在 UE 5.8 中，如果启用了 Toolset Registry，插件还会注册一组 AI 工具和工作流技能，让通过 MCP 连接的 AI 助手可以按“自动放置 → 检查列出的点 → 验证 → 征得你同意后绑定”的流程操作。

## 16. 推荐操作顺序

对于大多数标准人形模型，真正需要重点处理的只有三件事：

1. **选择符合要求的静态网格体**（非五指手先设置手指）；
2. **点击自动放置，检查并调整标记点**，尤其是报告中“请优先检查”的点和手指；
3. **根据报告决定**：直接绑定、处理问题后重新验证，或使用兼容模式 / 仅绑定骨骼。

然后用实际动画检查结果，并在 UE5 中手工调整权重，直到满足项目要求。
