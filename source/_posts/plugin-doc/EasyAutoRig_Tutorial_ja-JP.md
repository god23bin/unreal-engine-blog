## 1. EasyAutoRig でできること

EasyAutoRig は、T ポーズまたは A ポーズの**人型スタティックメッシュ（Static Mesh）**を Unreal Engine エディタ内で直接リギングし、アニメーションを再生できるキャラクターにします。1 回のリギングで次のアセットを生成します。

- UE5 標準人型スケルトンのボーン名と階層に従ってモデルにフィットしたスケルトン（Skeleton）。ツイストボーンと IK ボーンを含みます
- 初期自動スキンウェイトを持つスケルタルメッシュ（Skeletal Mesh）
- フィジックスアセット（Physics Asset、生成を無効にできます）

Blender や Maya などの DCC ソフトで、先にスケルトンを手作業で作る必要はありません。全体の流れは次のとおりです。

> アセット作成 → モデル選択 → ランドマーク自動配置 → ランドマーク確認 → リギング検証 → リギング → 結果確認 → UE5 でウェイトを手動調整

### 自動ウェイトについて

EasyAutoRig が生成する自動ウェイトは**初期ウェイト**であり、そのまま製品に使える完成品質のウェイトではありません。キャラクターを早く動かし、アニメーションや Gameplay を早い段階でテストするためのものです。

- リギング後も、**ウェイトの手動調整が必要です**。特に肩、脇、肘、手首、股関節／鼠径部、膝、指、服、髪、スカートなどを調整してください。
- 「使える」（アニメーションを再生でき、明らかなメッシュの破綻がない）ことは、製品品質に達していることを意味しません。
- トポロジー、体の比率、服、髪、分離したパーツが異なるため、必要な手動調整の量もキャラクターごとに異なります。

**ウェイトは UE5 内で直接調整できます**。DCC ソフトへの書き出しは不要です。UE 5.5 のスケルタルメッシュエディタには、標準でウェイト編集ツールが含まれています（第 11 節）。

推奨する使い方は次のとおりです。

> **スケルトンと初期ウェイトを素早く生成 → 早めにアニメーションをテスト → プロジェクトの要件を満たすまで UE5 でウェイトを手動調整**

## 2. モデルを準備する

EasyAutoRig は、**標準的でほぼ左右対称の二足歩行の人型キャラクター**に対応しています。開始前に次を確認してください。

- T ポーズまたは A ポーズであること。座り、走り、戦闘などの動作ポーズは非対応です。腕と脚を交差させないでください。
- キャラクターの正面がワールド `+Y`、頭頂方向が `+Z` を向いていること。
- 体がほぼ左右対称で、体の中心線が `X = 0` にあること。
- モデリング時にキャラクターの中心を原点に置き、足裏を `Z = 0` 付近に配置していること。

プラグインはモデルの回転、移動、修正を自動では行いません。向きや中心が不適切な場合は、DCC ソフトで修正して再インポートしてください。

モデルは**衣服のない素体である必要はありません**。服、靴、髪、スカート、マント、装飾品、複数の独立したメッシュの塊を含められます。構造が複雑なほど自動認識は難しくなりますが、可能な限りリギングを行い、重点的に確認すべき領域をレポートで知らせます。

## 3. EasyAutoRig アセットを作成する

コンテンツブラウザで右クリックし、**アニメーション → EasyAutoRig** を選択します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261536066.png)

アセット名を変更（例：`EAR_CharacterName`、`AR_CharacterName`）し、ダブルクリックで開きます。後で再調整できるよう、通常はキャラクターごとに 1 つの EasyAutoRig アセットを作ることを推奨します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261537233.png)

## 4. モデルを選択する

**詳細**パネルの**入力**カテゴリで、**ソーススタティックメッシュ（Source Static Mesh）**にリギングする人型モデルを指定します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261539791.png)

モデルがビューポートに表示されたら、T ポーズ／A ポーズであること、正面を向いていること、ほぼ左右対称であることを確認します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101619256.png)

初回は他の設定を既定値のままにしてください。ただし、**標準的な 5 本指の手ではない場合**（4 本指、指の節数が異なるなど）は、次に進む前に**スケルトン**カテゴリの**左手／右手**で**指の数**と各指のボーン数を設定します。左右が同じ場合は、左手を設定してから**左手を右手にコピー**をクリックできます。

## 5. エディタを理解する

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101623786.png)

**ツールバー**は 2 つのグループに分かれています。

| グループ                       | ボタン                                                       | 用途                                           |
| ------------------------------ | ------------------------------------------------------------ | ---------------------------------------------- |
| 切り替え（左側）               | ランドマーク編集、ランドマーク名、関節中心、リアルタイムミラー、スケルトンプレビュー | ビューポートでの編集可否や表示内容を切り替える |
| 操作（区切り線の右側、作業順） | 自動配置 → リギング検証 → リギング → スケルトンのみ          | 本ガイドの主要手順を実行する                   |

**パネル：**

- **ビューポート：**モデル、ランドマーク、スケルトンプレビューを表示し、ランドマークをクリック、ドラッグします。
- **ランドマーク：**一覧、現在の点の配置説明、確定、削除、関節中心、ハンドビューなどのツール。
- **レポート：**検証とリギングの結果、次に行う操作。
- **詳細：**ソースモデル、指、スキニング、物理などのアセット設定。
- **出力：**出力フォルダと生成したアセット。

各ボタンにはツールチップがあります。マウスポインタを重ねると説明を確認できます。

## 6. ランドマークを自動配置する

ランドマークはキャラクターの関節位置をプラグインに伝えます。**ランドマークを置いた位置に、対応するボーンの関節が生成されます**。1.1.0 から自動配置を利用できます。

ツールバーの**自動配置**をクリックします。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101625001.png)

プラグインはモデルを正面から見て体の関節を認識し、各手のハンドビューを個別に生成して指を認識した後、ランドマークを書き込みます。

1. 自動で検証を実行し、**レポート**パネルを開きます。配置数、保持した点、**優先して確認する点**が表示されます。
2. ツールバーの**ランドマーク編集**を有効にすると、**紫色の中空の円**が表示されます。これはプラグインによる推定点で、まだ確定されていません。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101628472.png)

次の点に注意してください。

- 自動配置は、**未配置**または**推定状態のまま**の点だけを変更します。手動配置、ドラッグ、ロックした点は変更しません。
- 自動配置全体が 1 回の操作です。`Ctrl + Z` でまとめて取り消せます。
- 握り拳、ミトン状の手、物を持った手などで指を認識できない場合は、理由をレポートに表示します。その手の指は手動で配置してください。**リアルタイムミラー**が有効な場合、認識できた片手の結果を両手に使います。
- 「自動配置でランドマークは変更されませんでした」と表示された場合は、信頼できる認識ができなかった可能性があります。例：極端なデフォルメ体型、+Y を向いていないモデル、モデルを描画できないエディタ環境。第 7.7 節の手動配置を行ってください。

## 7. ランドマークを確認・調整する

自動配置は実際の関節に近い結果になりますが、完全に正確とは限りません。リギング前に数分かけて確認し、**レポートに列挙された点を優先してください**。

### 7.1 編集用の切り替えを有効にする

ツールバーで**ランドマーク編集、ランドマーク名、関節中心、リアルタイムミラー、スケルトンプレビュー**を有効にします。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101631060.png)

- **ランドマーク編集：**クリックによる配置とドラッグを許可します。
- **ランドマーク名：**「左肩」「左肘」などの部位名を各点の横に表示します。
- **関節中心：**モデル表面ではなく、体の内部にある関節位置に配置します。ドラッグは指定平面内に制限されます。
- **リアルタイムミラー：**左側を編集すると右側が自動追従します。左右対称のキャラクターに適しています。
- **スケルトンプレビュー：**現在のランドマークから生成するスケルトンを表示します。

### 7.2 ランドマークの色を理解する

| ビューポートでの表示 | 意味                                         |
| -------------------- | -------------------------------------------- |
| 紫色の中空の円       | 自動配置または自動推定による、未確定の推定点 |
| 緑色                 | 配置済み、関節中心設定済み                   |
| 青色                 | モデル表面に配置済み、関節中心未設定         |
| オレンジ色           | 手動配置で次に配置する点                     |
| 外側に白い円         | 現在選択中の点                               |
| 半透明               | リアルタイムミラーで左側に追従する右側の点   |

**ランドマーク**パネル下部の一覧にも、**未配置、推定済み・未確定、関節中心設定済み、関節中心未設定**の状態が表示されます。

### 7.3 正面と側面から確認する

ビューポート左上のビューメニューやショートカットで方向を切り替えます。EasyAutoRig のキャラクターは `+Y` を向きますが、UE の「前／後／左／右」は UE 自身の座標軸に基づく名前のため、キャラクターの正面・側面とは一致しません。

| 見たい方向                     | UE 5.5                         | UE 5.8                 |
| ------------------------------ | ------------------------------ | ---------------------- |
| キャラクター正面（顔が見える） | 右（Right）、`Alt + Shift + K` | 左（Left）、`Alt + K`  |
| キャラクター側面               | 前（Front）、`Alt + H`         | 前（Front）、`Alt + H` |
| パースペクティブ               | `Alt + G`                      | `Alt + G`              |

他のエンジンバージョンでは、表示結果で判断してください。顔が見える方向が正面です。

- **正面から**高さと左右位置を確認します。
- **側面から**前後の奥行きを確認します。

関節点は皮膚や服の表面ではなく、**体の内部の関節中心**に置きます。肘は腕が曲がる関節の内部、膝は太ももとすねの間の関節内部です。迷った場合は『EasyAutoRig ランドマークをより適切に配置する方法』を参照してください。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101640071.png)

### 7.4 ドラッグで調整する

**ランドマーク編集**と**関節中心**を有効にし、ビューポートで点をドラッグします。点は制限平面内を移動し、緑色のワイヤーフレームが現在の平面ガイドです。

**ランドマーク**パネルの**関節中心**セクションでは細かな調整ができます。

- **ビュー平面／正面平面／側面平面：**ドラッグを制限する平面を選択します。
- **奥行き -／奥行き +：**選択点を前後に少しずつ移動します。
- **中心線：**骨盤、脊椎、首、頭の点を体の左右中心線に合わせます。
- **平面ガイドを表示／非表示、メッシュを表示／非表示：**点がモデルで隠れる場合は、一時的にモデルを非表示にできます。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101642389.png)

### 7.5 推定点を確定する

紫色の推定点には 2 つの特徴があります。

- 周囲の点を移動すると自動追従します。例：骨盤や首を動かすと、脊椎の点が再配置されます。
- ドラッグすると手動管理の点に変わり、自動更新されなくなります。

確認して位置が適切であれば、パネルの**ランドマーク**セクションで**この点を確定**（選択点）または**すべての推定点を確定**をクリックします。確定しても点は移動せず、周囲の点への追従だけが停止します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101643098.png)

未確定でもリギングできます。レポートには確認を促す案内が表示されるだけです。

### 7.6 指：ハンドビューを使う

指は全身表示では小さく、確認が困難です。1.1.0 で**ハンドビュー**が追加されました。

1. **ハンドビュー**セクションで**左手の甲、左手のひら、右手の甲、右手のひら**のいずれかをクリックします。
2. その手だけが表示され、指を上に向け、手の甲または手のひらに自動で視点を合わせます。
3. **関節中心**を有効にして指の点をドラッグすると、手のひらの平面内を移動します。クリック配置もその手だけを対象にします。
4. 確認後は**モデル全体を表示**で全身表示に戻ります。

その側の手首と肘のランドマークを先に配置してください。**リアルタイムミラー**が有効な場合、通常は左手だけの調整で十分です。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101645916.png)

### 7.7 手動配置（自動配置に失敗した場合、または自分で配置する場合）

1. **ランドマーク編集、関節中心、リアルタイムミラー**を有効にします。
2. パネル上部のカードに**次に配置する点：…**が表示され、ビューポートでは対応する点がオレンジ色で示されます。
3. モデルの該当位置をクリックし、次の点へ進みます。

リアルタイムミラー使用時の大まかな順序は、骨盤 → 首 1 → 頭 → 左肩 → 左肘 → 左手首 → 左手の各指の関節 → 左股関節 → 左膝 → 左足首 → 左足の母指球付近です。パネルの案内に従ってください。

すべてを手動配置する必要はありません。**脊椎、首の上部、鎖骨**は周囲の点を配置すると自動推定され（紫色）、パネルはそれらをスキップします。誤配置は**最後の点をクリア、選択した点を削除**で修正でき、**すべてのランドマークをリセット**で最初からやり直せます。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101648268.png)

## 8. リギングを検証する

確認後、ツールバーの**リギング検証**（または指引カードの**ランドマーク検証**）をクリックします。結果は**レポート**上部に表示されます。

| 状態                                 | 意味                                       | 対応                                       |
| ------------------------------------ | ------------------------------------------ | ------------------------------------------ |
| 基本チェック合格                     | リギングを妨げる問題は見つかりませんでした | リギングできます                           |
| リギング可能・警告を確認してください | 実行可能ですが注意事項があります           | 警告と次の手順を読み、調整するか判断します |
| リギング前に問題を解決してください   | 実行を妨げる問題があります                 | 次の手順のボタンで対処して再検証します     |

**次の手順**のボタンで問題箇所を直接確認できます。**左肘を確認**は点を選択して関節中心モードに入り、**不足ランドマークを配置**は最初の不足点を選択します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101650385.png)

**基本チェック合格は「リギングを開始できる」という意味だけです。すべての関節位置が完璧とは限りません。関節位置と動作結果は目視で確認してください。**

## 9. リギングする

ツールバーの**リギング**をクリックします。

- 実行前に自動で再検証します。警告がある場合は通知が表示され、**レポートを表示**で先に確認するか、**続行**でリギングできます。
- 進捗ウィンドウが表示されます。モデルのポリゴン数により、数秒から数十秒ほどかかります。

生成アセットは**出力**パネルの**出力フォルダ**に保存されます。既定値は `/Game/EasyAutoRig/Generated` です。通常は次を生成します。

- `SK_ModelName_Skeleton`：スケルトン
- `SKM_ModelName`：スケルタルメッシュ
- `PHYS_ModelName`：フィジックスアセット

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101655897.png)

## 10. リギング結果を確認する

完了後、**レポート**に**リギング結果を確認**カードが表示され、確認手順が順番に案内されます。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101657756.png)

1. **リギング済みモデルを開く**をクリックし、生成キャラクターをスケルタルメッシュエディタで開きます。
2. **プレビューシーン設定**の**プレビューコントローラ**を**指定アニメーションを使用**に設定し、このスケルトンにリターゲットしたアニメーションを選択します。
3. 腕を上げ、肩や脇に大きな潰れや伸びがないか確認します。
4. 肘と膝を曲げ、折れ込みや潰れがないか確認します。
5. 手を握る／開くアニメーションで指を確認します。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261543089.png)

ボーン位置のずれが原因で明らかに変形がおかしい場合（肘が腕の曲がる位置にないなど）は、EasyAutoRig アセットに戻り、ランドマークを調整して再検証・再リギングします。スケルトン位置が適切になったら、残る変形問題は次節のウェイト手動調整で修正します。

フィジックスアセットエディタの**シミュレート**で物理挙動を確認できます。通常は一部の剛体の位置や大きさを微調整するだけで済みます。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261543682.png)

## 11. UE5 でウェイトを調整する

自動ウェイトは初期ウェイトのため、リギング後に手動調整が必要です。UE 5.5 のスケルタルメッシュエディタには標準でウェイト編集ツールがあり、Blender や Maya に書き出さず UE5 内で作業できます。

1. 生成スケルタルメッシュを開きます（レポートの**リギング済みモデルを開く**も利用できます）。
2. ツールバーの **Editing Tools** をクリックし、**Skin** カテゴリの **Edit Weights** を選択します。
3. ボーン一覧で対象を選択し、ブラシでウェイトを描きます。**Add**（加算）、**Replace**（置換）、**Multiply**（乗算）、**Relax**（平滑化）を使用できます。
4. 頂点を選択し、**Mirror**（反対側にミラー）、**Flood**（選択範囲に一括適用）、**Prune**（小さすぎる影響を削除）、**Relax** なども使えます。
5. 調整後は **Accept** で適用してアセットを保存します。

プレビューアニメーションを再生しながら、肩と脇、肘、手首、股関節と鼠径部、膝、指、服、髪、スカート、装飾品を重点的に調整してください。左右対称の場合、片側を調整してから **Mirror** で反対側にコピーできます。

**Editing Tools** がない場合は、**編集 → プラグイン**で **Skeletal Mesh Editing Tools** を検索して有効にし、エディタを再起動します。UI 名称はエンジンバージョンや表示言語によって多少異なる場合があります。

## 12. 問題が起きた場合

- **「一部の領域に基本ウェイトを使用」と表示される：**スカートの下の股関節や独立メッシュで作られた手など、領域を確実に認識できなかった場合です。その領域だけに基本ウェイトを使い、他は通常どおりリギングします。該当領域のウェイトは粗いため、優先して手動調整してください。
- **「互換モードでリギング」ボタンが表示される：**このモデルでは高度な自動リギングが完了しませんでした。クリックするとランドマークを変更せず、UE Geodesic Voxel で基本ウェイトを生成します。高度なリギングより粗いため、肩、股関節、手、指にはより多くの手動調整が必要です。
- **スケルトンだけが必要：**ツールバーの**スケルトンのみ**でスケルトンと手動スキニング用のモデルアセットを生成し、自分でウェイトを描きます。
- **問題を報告したい：**レポートの**サポート用にレポートをコピー**、または**診断情報（テクニカルサポート用）**の**完全なレポートをコピー**をクリックし、モデルの正面／側面のスクリーンショットとともに god2333bin@gmail.com または god23bin@qq.com に送ってください。
