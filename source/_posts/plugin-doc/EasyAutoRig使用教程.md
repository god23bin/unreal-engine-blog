## 1. EasyAutoRig 能做什么？

EasyAutoRig 可以在 Unreal Engine 编辑器里，把一个 T Pose 或 A Pose 的**人形静态网格体（Static Mesh）**直接绑定成可以播放动画的角色。一次绑定会生成：

- 按 UE5 标准人形骨架命名和层级拟合的骨架（Skeleton），包含 Twist 骨骼、IK 骨骼
- 带初始自动蒙皮权重的骨骼网格体（Skeletal Mesh）
- 物理资产（Physics Asset，可关闭）

不需要先去 Blender、Maya 等 DCC 软件里手动搭骨架。整个流程是：

> 创建资产 → 选择模型 → 自动放置标记点 → 检查标记点 → 验证绑定 → 绑定 → 检查结果 → 在 UE5 中手工调整权重

### 关于自动权重

EasyAutoRig 生成的自动权重是**初始权重**，不是生产级权重。它的作用是让角色尽快有一套能动起来的权重，方便你尽早测试动画和 Gameplay。

- 绑定完成后，**仍然需要手工调整权重**，尤其是肩、腋下、肘、手腕、髋 / 腹股沟、膝、手指，以及衣服、头发、裙子等区域；
- 权重“能用”（能播放动画、没有明显破面）不代表已经达到生产级别；
- 不同角色的拓扑、比例、衣服、头发和分离部件都不同，需要手工调整的工作量也不同。

好消息是：**权重可以直接在 UE5 中调整**，不需要导出到 DCC 软件。UE 5.5 的骨骼网格体编辑器默认就带有权重编辑工具（见第 11 节）。

推荐的用法是：

> **快速生成骨架和初始权重 → 尽快测试动画 → 在 UE5 中手工调整权重，直到满足项目要求**

## 2. 准备模型

EasyAutoRig 支持**标准的左右对称双足人形角色**。开始前请确认模型满足：

- T Pose 或 A Pose（不支持坐姿、跑步、战斗等动作姿势，手臂和腿不能交叉）
- 角色正面朝向世界 `+Y`，头顶朝向 `+Z`
- 左右身体基本对称，身体中线位于 `X = 0`
- 模型在建模时以原点为角色中心，脚底在 `Z = 0` 附近

插件不会自动旋转、移动或修正模型。如果朝向或中心不对，请先在 DCC 软件中修正后重新导入。

模型**不需要是裸模**：衣服、鞋子、头发、裙子、披风、饰品、多个独立网格块都可以。结构越复杂，自动识别越困难，但插件会尽量完成绑定，并在报告中告诉你哪些区域需要重点检查。

## 3. 创建 EasyAutoRig 资产

在内容浏览器中右键，选择「动画 → EasyAutoRig」，即可创建 EasyAutoRig 资产。

![创建 EasyAutoRig 资产](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261536066.png)

重命名该资产（例如 `EAR_角色名`、`AR_角色名`），然后双击打开。一般建议一个角色对应一个 EasyAutoRig 资产，以后想重新调整时再次打开即可。

![重命名该资产](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261537233.png)

## 4. 选择模型

在「细节」面板的「输入」分类中，把「源静态网格体（Source Static Mesh）」设置为需要绑定的人形模型。

![选择源静态网格体](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261539791.png)

选择完成后，模型会显示在视口中。先确认它是 T Pose / A Pose、正面朝向你、左右基本对称。

![模型显示在视口中](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101619256.png)

其他设置第一次使用时保持默认即可。只有一种情况需要先改：**角色不是标准五指手**（例如只有四根手指，或某根手指的骨节数不同）。这时请在「细节」面板的「骨架」分类中，先按模型实际情况设置「左手 / 右手」的「手指数量」和各手指骨骼数（左右手相同时，可以设置好左手后点击「将左手复制到右手」），再进行下一步。

## 5. 认识编辑器

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101623786.png)

**工具栏**分为两组：

| 分组                               | 按钮                                             | 作用                               |
| ---------------------------------- | ------------------------------------------------ | ---------------------------------- |
| 开关（左侧）                       | 编辑标记、标记名称、关节中心、实时镜像、骨骼预览 | 控制视口里能否编辑标记点、显示什么 |
| 操作（分隔线右侧，按工作顺序排列） | 自动放置 → 验证绑定 → 绑定 → 仅绑定骨骼          | 依次执行本指南的主要步骤           |

**面板**：

- **视口**：显示模型、标记点和骨骼预览，在这里点击和拖动标记点。
- **标记**：标记点列表、当前点的放置说明，以及确认、删除、关节中心、手部视图等工具。
- **报告**：验证和绑定的结果，以及“下一步”该做什么。
- **细节**：资产设置（源模型、手指、蒙皮、物理）。
- **输出**：输出目录和生成的资产。

所有按钮都有提示文字（Tool Tip），把鼠标停在按钮上即可查看。

## 6. 自动放置标记点

标记点（Landmark）告诉插件角色的关节在哪里，**标记点放在哪里，对应的骨骼关节就会生成在哪里**。1.1.0 起可以让插件自动放置。

点击工具栏的「**自动放置**」。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101625001.png)

插件会从正面观察模型，识别出身体关节，再为每只手单独生成手部视图识别手指，然后写入标记点。

1. 插件会自动做一次验证。「报告」面板自动打开，说明放了多少个点、保留了哪些点、**哪些点请优先检查**；
2. 在工具栏中开启「编辑标记」，视口中出现一组**紫色空心圈**，表示这些点是插件估算的，尚未确认；

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101628472.png)

需要知道的几点：

- 自动放置只改**未放置**或**仍是估算状态**的点，你自己放过、拖动过或锁定的点不会被改动。
- 整个自动放置是一步操作，按 `Ctrl + Z` 可以一次撤销。
- 如果某只手的手指没能识别（例如握拳、手套状的手、手里拿着东西），报告会写明原因，这只手的手指需要手动放置。开启「实时镜像」时，一只手识别成功就会用于两只手。
- 如果弹出“自动放置未更改任何标记点”的通知，说明这个模型无法可靠识别（例如 Q 版大头比例、模型没有朝向 +Y、当前编辑器无法渲染模型）。这时请按第 7.7 节手动放置。

## 7. 检查和调整标记点

自动放置的结果接近真实关节，但不一定完全准确。绑定前请花几分钟检查，**优先检查报告中列出的点**。

### 7.1 打开编辑开关

在工具栏中开启：「编辑标记」「标记名称」「关节中心」「实时镜像」「骨骼预览」

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101631060.png)

- **编辑标记**：允许在视口中点击放置、拖动标记点。
- **标记名称**：在每个点旁边显示身体部位名称，例如“左肩”“左肘”。
- **关节中心**：让点落在身体内部的关节位置，而不是模型表面；拖动时沿限制平面移动。
- **实时镜像**：只需要编辑左侧，右侧自动跟随（适合左右对称的角色）。
- **骨骼预览**：按当前标记点显示将要生成的骨架。

### 7.2 看懂标记点颜色

| 视口中的样子   | 含义                                       |
| -------------- | ------------------------------------------ |
| 紫色空心圈     | 估算点（自动放置或自动推算得到），尚未确认 |
| 绿色           | 已放置，关节中心已设置                     |
| 蓝色           | 已放置在模型表面，关节中心未设置           |
| 橙色           | 手动放置时，下一个要放的点                 |
| 外面多一圈白色 | 当前选中的点                               |
| 半透明         | 开启实时镜像时，由左侧带动的右侧点         |

「标记」面板下方的列表也会显示每个点的状态：「未放置」「已估算，未确认」「关节中心已设置」「关节中心未设置」。

### 7.3 从正面和侧面检查

使用视口左上角的视图菜单切换观察方向，也可以用快捷键。注意：EasyAutoRig 的角色面向 `+Y`，而 UE 视图菜单中的“前 / 后 / 左 / 右”是按 UE 自己的坐标轴命名的，和角色的正面、侧面并不对应：

| 想看                 | UE 5.5                                 | UE 5.8                         |
| -------------------- | -------------------------------------- | ------------------------------ |
| 角色正面（能看到脸） | 「右（Right）」视图，`Alt + Shift + K` | 「左（Left）」视图，`Alt + K`  |
| 角色侧面             | 「前（Front）」视图，`Alt + H`         | 「前（Front）」视图，`Alt + H` |
| 透视                 | `Alt + G`                              | `Alt + G`                      |

其他引擎版本以画面为准：能看到角色的脸就是正面。

- **从正面**检查高度和左右位置；
- **从侧面**检查前后深度。

关节点应该在**身体内部的关节中心**，而不是贴在皮肤或衣服表面。例如肘点在手臂弯曲处的内部，膝点在大腿和小腿之间的内部。不确定该放在哪里时，可以参考《EasyAutoRig 如何更好地放置标记？》。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101640071.png)

### 7.4 拖动调整

在开启「编辑标记」和「关节中心」的状态下，直接在视口中拖动标记点即可调整。拖动时点会沿限制平面移动，绿色线框就是当前的平面辅助线。

「标记」面板的「**关节中心**」分区提供更精细的工具：

- 「视图平面」「正面平面」「侧面平面」：选择拖动时限制在哪个平面里；
- 「深度 -」「深度 +」：把选中点前后移动一小步；
- 「中心线」：把骨盆、脊柱、颈部、头部的点移到身体左右中线上；
- 「显示 / 隐藏平面辅助线」「显示 / 隐藏网格体」：模型挡住标记点时可以临时隐藏模型。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101642389.png)

### 7.5 确认估算点

紫色的估算点有两个特点：

- 移动周围的点时，它会自动跟着更新（例如移动骨盆或颈部，脊柱点会跟着重新分布）；
- 你一旦拖动它，它就变成你自己的点，不再自动更新。

检查后觉得位置合适，可以在「标记」面板的「**标记点**」分区中点击「**确认此点**」（确认选中的点），或「**确认全部估算点**」。确认后点不会移动，只是不再跟随周围的点。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101643098.png)

不确认也可以绑定，报告只会提醒你检查这些点。

### 7.6 手指：使用手部视图

手指很小，在全身视图里不好看清。1.1.0 新增了「**手部视图**」：

1. 在「标记」面板的「手部视图」分区中点击「左手手背」「左手手掌」「右手手背」或「右手手掌」；
2. 视口中只显示这一只手，手指朝上，并自动对准手背或手掌；
3. 开启「关节中心」后拖动手指点，点会沿手掌平面移动；单击放置也只会落在这只手上；
4. 检查完点击「**显示完整模型**」回到全身。

手部视图需要这一侧的手腕和手肘标记点已经放好。开启「实时镜像」时，一般只需要调整左手。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101645916.png)

### 7.7 手动放置（自动放置失败或想自己放时）

1. 开启「编辑标记」「关节中心」「实时镜像」；
2. 「标记」面板顶部的卡片会显示「**下一个放置点：…**」，视口中对应的点以橙色提示；
3. 在模型上点击对应位置，然后继续下一个。

开启实时镜像时，放置顺序大致是：骨盆 → 颈部 1 → 头部 → 左肩 → 左肘 → 左手腕 → 左手各手指关节 → 左髋 → 左膝 → 左脚踝 → 左前脚掌，以面板提示为准。

不需要手动放所有点：**脊柱、上颈部和锁骨的点**会在周围的点放好后自动估算（紫色），面板会跳过它们。放错时可以使用「清除最后一个」「删除选中的」，或「重置所有标记」从头开始。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101648268.png)

## 8. 验证绑定

标记点检查完后，点击工具栏的「**验证绑定**」（或「标记」面板卡片中的「验证标记点」）。结果显示在「报告」面板顶部：

| 状态                     | 含义                         | 怎么做                                     |
| ------------------------ | ---------------------------- | ------------------------------------------ |
| 基础检查通过             | 没有发现会阻止绑定的问题     | 可以绑定                                   |
| 可以开始绑定，请检查警告 | 可以绑定，但有需要留意的地方 | 先看「警告」和「下一步」，再决定是否调整   |
| 请先处理问题，再进行绑定 | 发现了会阻止绑定的问题       | 按「下一步」中的按钮处理，然后「重新验证」 |

「下一步」中的按钮可以直接带你去处理问题，例如「检查左肘」会选中这个点并进入关节中心模式，「补齐缺失标记点」会选中第一个缺失的点。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101650385.png)

**注意：基础检查通过只代表“可以开始绑定”，不代表每个关节位置都完美，关节位置和动作效果仍需要你目视检查。**

## 9. 绑定

点击工具栏的「**绑定**」。

- 绑定前会自动再验证一次。如果有警告，会弹出通知，可以选择「查看报告」先看看，或「继续」直接绑定；
- 绑定过程中会显示进度窗口，短则几秒，长则几十秒，取决于模型面数；

生成的资产保存在「**输出**」面板中设置的「输出目录」里，默认是 `/Game/EasyAutoRig/Generated`。通常包括：

- `SK_模型名_Skeleton`：骨架
- `SKM_模型名`：骨骼网格体
- `PHYS_模型名`：物理资产

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101655897.png)

## 10. 检查绑定结果

绑定完成后，「报告」面板会显示「**检查绑定结果**」卡片，按顺序给出检查步骤：

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101657756.png)

1. 点击「**打开已绑定模型**」，在骨骼网格体编辑器中打开生成的角色；
2. 在「预览场景设置」中，把「预览控制器」设为「使用指定动画」，选择重定向到该骨架的动画；
3. 抬起手臂，观察肩部和腋下有没有明显塌陷或拉伸；
4. 弯曲肘部和膝部，观察弯曲处有没有夹折或塌陷；
5. 用握拳 / 张开手的动画检查手指。

![绑定结果](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261543089.png)

如果某处变形明显不对，并且是骨骼位置偏了（例如肘关节不在手臂弯曲处），先回到 EasyAutoRig 资产调整标记点，再重新验证和绑定。骨架位置合理后，剩下的变形问题需要按下一节手工调整权重。

物理资产可以在物理资产编辑器中点击「模拟」查看效果。一般只需要微调个别刚体的位置和大小。

![物理资产模拟](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261543682.png)

## 11. 在 UE5 中调整权重

自动权重是初始权重，绑定后需要手工调整。UE 5.5 的骨骼网格体编辑器默认带有权重编辑工具，可以直接在 UE5 中完成，不需要导出到 Blender 或 Maya：

1. 打开生成的骨骼网格体（可以在报告中点击「打开已绑定模型」）；
2. 点击工具栏中的「Editing Tools」，切换到「Skin」分类，选择「Edit Weights」；
3. 在骨骼列表中选中要调整的骨骼，用笔刷绘制权重：Add（增加）、Replace（替换）、Multiply（相乘）、Relax（平滑）；
4. 也可以选中一部分顶点，使用 Mirror（镜像到另一侧）、Flood（整体赋值）、Prune（清除过小的影响）、Relax 等操作；
5. 调整完成后点击「Accept」应用，再保存资产。

建议一边播放预览动画一边调整，重点处理肩和腋下、肘、手腕、髋和腹股沟、膝、手指，以及衣服、头发、裙子、饰品。左右对称的角色可以先调好一侧，再用 Mirror 镜像到另一侧。

如果工具栏中没有「Editing Tools」，请在「编辑 → 插件」中搜索并启用「Skeletal Mesh Editing Tools」，重启编辑器。界面名称可能因引擎版本和编辑器语言略有不同。

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202610101700001.png)

## 12. 遇到问题时

- **报告提示“部分区域使用了基础权重”**：插件没能可靠识别某个身体区域（例如裙子下的髋部、单独网格块做的手），只有这些区域使用基础权重，其余部分照常绑定。这些区域的权重更粗略，绑定后要优先手工调整。
- **报告中出现「使用兼容模式绑定」按钮**：这个模型没能完成高级自动绑定。点击它会用 UE Geodesic Voxel 生成基础权重，你的标记点不会被修改。兼容模式的权重比高级绑定更粗略，肩、髋、手和手指需要更多手工调整。
- **只想要骨架**：点击工具栏的「**仅绑定骨骼**」，会生成骨架和供手动蒙皮使用的模型资产，之后自己绘制权重。
- **需要反馈问题**：在报告中点击「复制报告供技术支持」（或在「诊断信息（供技术支持）」中点击「复制完整报告」），连同模型正面 / 侧面截图一起发给我。我的邮箱：god2333bin@gmail.com 或者 god23bin@qq.com

> **EasyAutoRig 帮你快速完成骨架和初始权重，让角色尽快动起来；要达到生产级别的变形效果，仍需要在 UE5 中手工调整权重。**
