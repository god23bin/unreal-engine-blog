## 获取 AES 加密密钥

### 下载 AES-Finder

https://github.com/mmozeiko/aes-finder

如果你没有任何编程经验或者不想安装相关开发环境，可以选择下载我编译的版本：【】；下载后可跳过下面的步骤

### 开发环境（没有编程经验可以跳过）

下载MSYS2并安装：https://mirrors.cloud.tencent.com/msys2/distrib/msys2-x86_64-latest.exe

将下列MSYS2路径添加到系统PATH：

- [安装目录]\mingw64\bin
- [安装目录]\mingw32\bin
- [安装目录]\usr\bin
- [安装目录]\clang64\bin
- [安装目录]\ucrt64\bin
- [安装目录]\clang32\bin

接着双击打开 msys2.exe

执行下列命令进行全局更新

```shell
pacman -Syu
```

完成后通过以下命令安装编译环境

```shell
pacman -S git git-extras git-flow mingw-w64-x86_64-toolchain --noconfirm
```

找一个你要存放 AES-Finder 的位置，运行 cmd 或者 Git Bash（前提是安装 Git）

```shell
# 下载 aes-finder
git clone https://github.com/mmozeiko/aes-finder.git
cd aes-finder
# 编译得到可执行文件 aes-finder-x64.exe
g++ aes-finder.cpp -o aes-finder-x64.exe
```

### 使用 AES-Finder

1. 运行游戏
2. 打开任务管理器找到游戏程序其对应的 PID （进程 ID），记录游戏的 PID

![记录游戏的 PID](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261201428.png)

3. 在 aes-finder 目录中运行 cmd，执行 `aes-finder-64.exe -[PID]` 命令

![image-20250215184817567](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261201237.png)

## 注入 DLL 生成 Mappings.usmap 文件

DLL 注入工具：

UnrealMappingsDumper：[https://github.com/TheNaeem/UnrealMappingsDumper](https://github.com/TheNaeem/UnrealMappingsDumper)

1. 运行游戏
2. 打开 DLL 注入工具
3. 找到游戏进程，注入 `UnrealMappingsDumper.dll`
4. 成功注入会在游戏应用程序同一目录下生成 `Mappings.usmap` 文件

## 解包工具

FModel：[https://github.com/4sval/FModel/releasesopen in new window](https://github.com/4sval/FModel/releases)

UE Viewer：https://www.gildor.org/en/projects/umodel

1. 下载 FModel 并运行，选择需要解包的游戏所在目录

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261201578.png)

2. 点击顶部工具栏中 Settings，设置 Mappings.usmap；确保 UE 版本正确、勾选 Local Mapping File，Mapping File Path 选择 Mappings.usmap

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261201111.png)

3. 成功加载游戏文件

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261201185.png)

4. 点击顶部菜单栏 Directory -> AES，输入之前获取到的 AES 加密密钥

![](https://pic-bed-of-god23bin.oss-cn-shenzhen.aliyuncs.com/img/202608261201939.png)
